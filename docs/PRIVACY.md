# プライバシーポリシー

最終更新日: 2026年11月9日

md-publisher-api(以下「本サービス」)が、どの情報を、何のために、どのくらいの期間保存するかを説明します。

## 保存する情報

| 情報 | 内容 | 期間 |
|---|---|---|
| 文書 | 投稿された Markdown の本文、タイトル、作成日時と更新日時 | 公開から30日(最長90日)。利用者が削除するとすぐに消えます |
| 編集トークン | 利用者が文書を更新・削除するための値。保存するのはハッシュだけで、トークンそのものは保存しません | 文書と同じ |
| 利用回数 | 投稿の回数と容量。IPアドレスそのものではなく、運営者だけが知る鍵で変換した値(ハッシュ)に結びつけて数えます | 最大2日 |

アカウントや氏名、メールアドレスは集めません。

## 利用目的

- 投稿された文書を、URL を知る人に表示するため。
- 過度な投稿を防ぎ、悪用に対処するため(回数と容量の制限)。

広告や分析のために使うことはなく、第三者に販売もしません。

## 保存場所と提供先

- 本サービスは Cloudflare のサービス(Workers と KV)で動いています。文書と上記の情報は、Cloudflare に保存され、Cloudflare を通じて配信されます。
- 文書の URL を知る人は、その文書を読めます。
- 法令に基づく開示の求めがあったときは、法令の範囲で対応します。

## 画像と外部リンク

文書内の画像は表示せず、リンクとして表示します。読む人のブラウザが、投稿者の指定した外部サイトに自動で接続することはありません。

## 削除の依頼

- 自分が投稿した文書は、編集トークンで削除できます。
- 自分の情報が他人の文書に載っているときは、下記の連絡先に、文書の URL を添えて知らせてください。

## 変更

このポリシーは変更することがあります。変更したときは、この文書の更新日を改めます。
