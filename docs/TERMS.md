# 利用規約

最終更新日: 2026年11月9日

md-publisher-api(以下「本サービス」)は、Markdown を API で送ると、その内容を Web ページとして公開するサービスです。本サービスを使った時点で、この規約に同意したものとみなします。

## 使える人と使い方

- 誰でも、登録なしで使えます。
- 公開した文書は、URL を知っている人なら誰でも読めます。URL は推測できない文字列ですが、秘密の保管場所ではありません。
- 公開のとき、文書を更新・削除するための編集トークンが一度だけ返されます。紛失しても再発行はできません。トークンを持つ人だけが、その文書を更新・削除できます。

## 投稿してはいけないもの

- 法令に違反する内容、他人の権利(著作権、プライバシー、名誉)を侵害する内容。
- 他人の個人情報や、パスワード、キー、トークンなどの秘密情報。
- フィッシング、マルウェア、詐欺への誘導を目的とする内容。
- 迷惑なメッセージ(スパム)、嫌がらせ、人を傷つける内容。
- 本サービスを、大量の投稿や自動化で過度に負荷をかけて使うこと。

## 保存期間と制限

- 文書は、公開から30日で自動的に削除されます。`expires_in_days` で、1日から90日までの範囲で指定できます。
- 1つの文書は 200KB までです。これを超える文書は、複数に分けて公開してください。
- 1つのIPアドレスからの投稿には、回数と容量の上限があります。上限は変更することがあります。
- 文書の削除は、編集トークンで利用者自身ができます。

## 削除と通報

- この規約に反する文書は、運営者が予告なく削除します。投稿が多すぎる場合は、そのアクセス元の利用を制限することがあります。
- 問題のある文書を見つけたときは、下記の連絡先に、文書の URL を添えて知らせてください。確認して削除します。
- 権利を侵害されたと考える人も、同じ連絡先に知らせてください。

## 免責

- 文書の内容は利用者が投稿したもので、運営者はその正確さや安全性を保証しません。リンク先にも注意してください。
- 本サービスは現状のまま提供します。保存した文書が消えることがあります。大事な文書は、手元に控えを残してください。運営者は、故意または重大な過失がある場合を除いて、本サービスの利用で生じた損害に責任を負いません。
- 予告なく、機能の変更、制限、停止をすることがあります。

## 規約の変更

この規約は変更することがあります。変更後も使い続けた場合は、変更後の規約に同意したものとみなします。
